## 关于 Quiet Archive

这是一座安静的个人档案馆。

它不追求流量，不追求热度，不追求社交互动。它只做一件事：**把值得留下的东西，安静地留下来。**

### 为什么叫「静档」

「静」是安静，是克制，是不被打扰的阅读体验。
「档」是档案，是记录，是对时间的尊重。

每一篇文章、每一条笔记、每一个实验，都是某个时刻的思考切片。它们不需要被点赞、被转发、被算法推荐。它们只需要在这里，等待未来某一天被重新翻阅。

### 这里有什么

- **文章**：经过思考和组织的长文，通常关于技术、架构或工程哲学
- **笔记**：短小的想法碎片，可能是灵感、可能是备忘
- **专栏**：围绕某个主题的系列写作，有连续性和结构

### 技术实现

这个档案馆本身也是一个技术实践：

- 纯静态构建，无运行时依赖
- 文件系统驱动，Markdown 即事实来源
- API 优先，内容既喂页面也喂 Agent
- 设计上追求长期可维护、可迁移
